        Class mapping
        
            
        Choose a target or explicitly exclude each source category. Original class names remain in provenance.
        
            
        
            
        
            
        
              IRIS class definitions
              
        Person: a visible human, including a rider. Enclose the visible extent of each person; do not infer a box for a fully occluded person.
        
              
        Car: a passenger car, including an SUV or passenger minivan. Exclude buses, trucks, motorcycles and bicycles. Enclose the visible extent of each car.
        
              
        Review every image for missing objects, including images with no imported target boxes.
