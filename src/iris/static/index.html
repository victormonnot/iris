                    Local multimodal review
                    

                      

                        Checking local model availability…
                      

                      
                    

                    

                      Reviews the selected image and up to eight candidate crops
                      using local Ollama. It can question a class or flag
                      uncertainty; it does not find new box coordinates. You
                      remain responsible for missed objects and final
                      validation.
                    

                    

                      Set up the local vision model
                      

                        Install Ollama, then run the following command in a
                        terminal. This downloads a multi-gigabyte model and uses
                        local memory; IRIS never starts the download.
                      

                      
ollama pull qwen3-vl:4b-instruct

                      

                        Start Ollama on its default loopback address, then
                        refresh availability. Manual annotation and detector
                        proposals work without it.
