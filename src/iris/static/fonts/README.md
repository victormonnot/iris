# IRIS Studio fonts

These WOFF2 files are unmodified copies distributed by Google Fonts, downloaded
on 2026-09-07. They are bundled locally so IRIS needs no external font
service. The upstream font licences and copyright notices are included here and
must remain with redistributed copies.

| Family | CSS weight | Files | Licence |
| --- | --- | --- | --- |
| IBM Plex Sans | `400 500` | `ibm-plex-sans-400-500-latin*.woff2` | `IBM-Plex-Sans-OFL.txt` |
| IBM Plex Mono | `400` | `ibm-plex-mono-400-latin*.woff2` | `IBM-Plex-Mono-OFL.txt` |
| IBM Plex Mono | `500` | `ibm-plex-mono-500-latin*.woff2` | `IBM-Plex-Mono-OFL.txt` |
| Marcellus | `400` | `marcellus-400-latin*.woff2` | `Marcellus-OFL.txt` |

All faces are upright. IBM Plex Sans is a variable font: Google Fonts supplies
the same binary for the requested 400 and 500 weights. Each family includes the
Google Fonts `latin` and `latin-ext` subsets. Together they include accented
French letters and the Œ/œ ligatures (Ÿ uses `latin-ext`). No font outlines, names or metadata have
been modified locally; only the filenames have been made descriptive.

Marcellus copyright: © 2012 Brian J. Bonislawsky DBA Astigmatic (AOETI),
Reserved Font Name "Marcellus".
All three families use the SIL Open Font License 1.1.
